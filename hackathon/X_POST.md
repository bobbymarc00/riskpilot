## Project

**RiskPilot — Binance Agent OS Mini Hackathon Track A**

RiskPilot is a Binance Agent OS-powered Spot trading copilot combining:

* deterministic market scoring;
* narrowly scoped Agent OS verification;
* deterministic risk controls;
* immutable LIVE proposals;
* human-approved real-fund execution;
* protected OTOCO / OCO Spot workflows;
* partial exit with protection re-arm;
* fail-closed execution boundaries.
